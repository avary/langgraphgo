Implementation Notes

Issue #100 — 精简: 移除/隔离 memory 中的 langchaingo 兼容垫片 — 2026-07-08

Design Decisions

Decision New subpackage memory/langchainadapter as the sole langchaingo importer

Ambiguity: The issue said "迁移到独立子包(如 memory/langchainadapter)" but did not name the package or specify what moves.

Choice: Moved the entire adapter file (types ChatMemory, LangChainMemory, ChatMessageHistory and their methods) verbatim into package langchainadapter via git mv, preserving history.

Rationale: ChatMemory is referenced only by the adapter itself, so nothing had to stay in the core package. go list -deps ./memory now reports zero tmc/langchaingo dependencies — the stated goal.

Deviations

Deviation Examples repointed to the adapter, not rewritten to native Buffer/SlidingWindow

Spec: Suggestion #3 said "更新 examples 使用原生 Buffer/SlidingWindow 构造函数".

Implemented: examples/memory_basic and examples/memory_chatbot keep using the langchain adapter, only switching their import to the new langchainadapter subpackage.

Why: The native BufferMemory API is structurally different (message-object AddMessage/GetContext vs the adapter's map-based SaveContext/LoadMemoryVariables and langchain options like WithMemoryKey/WithReturnMessages). These examples exist specifically to demonstrate the langchain-compatible surface, so rewriting them would delete that demonstration rather than update it. The dependency-isolation goal is fully met regardless of which constructor the examples call.

Tradeoffs

Tradeoff Fixed the affected docs in place instead of a full rewrite

Alternatives: (a) leave docs untouched; (b) fully rewrite the LangChain integration docs; (c) minimally correct only what this change broke.

Chosen (c): Removed the ConversationTokenBuffer section (its constructor was deleted), corrected the long-stale prebuilt. prefix to langchainadapter., and added an import snippet — in both EN and CN docs.

Why: (a) would ship docs referencing a deleted symbol; (b) is a separate docs task beyond this issue's scope. (c) keeps the shipped tree self-consistent with minimal blast radius.
